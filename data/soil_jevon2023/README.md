# Soil CH4 fluxes used for comparison (third-party data, not redistributed here)

Jevon, F. (2023). CO2 and CH4 fluxes at Harvard Forest. Mendeley Data, V2. https://doi.org/10.17632/z6wybrtpyk.2
(data for Jevon et al. 2023, Ecosystems 26:1587–1602).

To reproduce the soil comparison, download `fluxes.csv` from the Mendeley record into this folder.
The scripts use the July–August CH4 fluxes (column `CH4.flux`, µmol m-2 s-1; converted to nmol m-2 s-1).
